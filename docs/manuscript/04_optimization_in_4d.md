# Discrete Lattice Search and Fisher-Preconditioned Updates {#optimization-in-4d}

## Implemented optimizers and their limits

This section covers lattice-adapted Nelder–Mead, greedy twelve-neighbor descent, and continuous damped metric increments. A four-vertex simplex spans at most three spatial dimensions. Exact rational volumes diagnose its geometry; they do not force monotone shrinkage or global convergence. [Extensions](05_extensions.md) separates unimplemented generalizations.

## Nelder–Mead on Integer Lattice

- **Adaptation**: the four standard simplex operations — reflection ($\alpha$), expansion ($\gamma$), contraction ($\rho$), and shrink ($\sigma$) — applied to a simplex of four lattice points, with the objective $f$ evaluated on the embedded coordinates $(x, y, z)$ of each vertex.
- **Projection**: candidate moves are formed with per-component integer truncation of the scaled offsets (the centroid of the best three uses floor division), then mapped back to the canonical lattice representative by projective normalization, so the entire trajectory stays on the lattice.
- **Volume tracking**: monitor the exact IVM tetravolume (absolute quadray determinant divided by 4, kept as an exact Fraction; Section 3) as a convergence diagnostic; discrete steps create stable volume plateaus.
- **Degenerate-simplex restart**: When volume is zero and objective spread is below tolerance, the implementation probes $\pm1$ and $\pm2$ steps along each Quadray axis from the best vertex. An improving probe triggers a full-volume restart along three selected axes; otherwise the run stops. This is a finite local probe criterion, not a global optimality certificate. Component rounding means the discrete proposals are not exact affine Nelder–Mead operations.

### Parameters

- **Reflection** $\alpha \approx 1$
- **Expansion** $\gamma \approx 2$
- **Contraction** $\rho \approx 0.5$
- **Shrink** $\sigma \approx 0.5$

References: original Nelder–Mead method and common parameterizations in optimization texts and survey articles; see overview: [Nelder–Mead method](https://en.wikipedia.org/wiki/Nelder%E2%80%93Mead_method).

## Volume-Level Dynamics

- Simplex tetravolumes lie on the quarter-unit grid, but expansion, truncation, and restart can increase them. Plateaus are diagnostics, not physical energy levels.
- A collapsed simplex with sufficiently small spread triggers the finite axis-probe/restart rule. Nonzero spread or the iteration budget may also limit a run; volume alone does not establish convergence.
- Monitoring: record best/worst objective, spread, and exact IVM volume at each iteration (see `simplex_trace.png` below).

## Quadray Lattice Optimization Pseudocode {#code:nelder_mead_on_integer_lattice}

```text
while not converged:
  order vertices by objective
  centroid of best three
  propose reflected (then possibly expanded/contracted) point
  accept per standard tests; else shrink toward best
  if simplex volume is zero and spread is below tolerance:
    probe +/-1 and +/-2 lattice steps along each quadray axis from best
    if any probe improves best: restart (full-volume simplex along 3 best axes); else stop
  update exact rational volume and function spread trackers
```

## Discrete Lattice Descent (Information-Theoretic Variant)

- Greedy descent over integer FCC locations: evaluate a real-valued objective at the twelve nearest neighbors (distinct permutations of $(2,1,1,0)$ as Quadray offsets), then select the minimizing neighbor.
- Each accepted move strictly decreases $f$. The walk stops when no neighbor improves, or at its iteration budget. An unbounded strictly decreasing real-valued sequence need not terminate; only the no-improvement stop certifies a minimum over the current twelve-neighbor adjacency.
- The objective may be geometric (e.g. Euclidean distance in an embedding) or information-theoretic (e.g. a local free-energy proxy).
- API: `discrete_ivm_descent` in `src/quadmath/optimize/discrete_variational.py`. Animation helper: `animate_discrete_path` in `src/quadmath/viz/visualize.py`.

Short snippet (paper reproducibility):

```python
from quadmath.core.quadray import Quadray, DEFAULT_EMBEDDING, to_xyz
from quadmath.optimize.discrete_variational import discrete_ivm_descent
from quadmath.viz.visualize import animate_discrete_path

def f(q: Quadray) -> float:
    x, y, z = to_xyz(q, DEFAULT_EMBEDDING)
    return (x - 0.5)**2 + (y + 0.2)**2 + (z - 0.1)**2

path = discrete_ivm_descent(f, Quadray(6,0,0,0))
animate_discrete_path(path)
```

## Convergence and Robustness

- Integer labels avoid coordinate drift in the representation, but embedding evaluations and objectives remain floating-point where used.
- Volume quantization alone proves neither stability improvement nor fewer evaluations relative to a Cartesian baseline.
- Fisher-guided continuous proposals are possible compositions, not a built-in hybrid of these two discrete optimizers.

## Information-Geometric View (Einstein.4D analogy in metric form)

The Fisher Information Matrix (FIM) provides a fundamental bridge between the three 4D frameworks, establishing a Riemannian metric on parameter space that guides optimization through information geometry. This section demonstrates how the FIM connects Coxeter.4D (Euclidean parameter space), Einstein.4D (information-geometric flows), and Fuller.4D (tetrahedral structure) in a unified optimization framework.

### Fisher Information as Riemannian Metric

The population Fisher matrix is a metric on identifiable model directions. An empirical score outer product estimates it when observations follow the model and the usual integrability assumptions hold. The implementation also accepts arbitrary sample gradients; in that case the result is a Gram matrix, not automatically Fisher information or a loss Hessian.

For a model with parameter vector $\theta$ and per-sample scores $\partial_{\theta_i} \log p(x_n; \theta)$, the empirical FIM is the average outer product of score functions, $F_{i,j} = \frac{1}{N} \sum_{n=1}^{N} \partial_{\theta_i} \log p(x_n; \theta)\, \partial_{\theta_j} \log p(x_n; \theta)$ (Eq. \eqref{eq:fim_empirical} in the equations appendix). Diagonal entries quantify parameter sensitivity and off-diagonal entries pairwise parameter interactions. The running example below keeps the parameter names $\mathbf{w} = (w_0, w_1, w_2)$ used by `information_demo.py`; the two notations coincide.

For positive-definite $F$, $F^{-1}\nabla L$ is the metric steepest-descent direction. A geodesic instead solves a second-order metric equation with initial position and velocity. These paths generally differ; the implementation does not solve a geodesic equation.

The theoretical foundation of this approach stems from the work of [Rao (1945)](https://en.wikipedia.org/wiki/Cram%C3%A9r%E2%80%93Rao_bound) and [Amari (1985)](https://en.wikipedia.org/wiki/Shun-ichi_Amari), who established information geometry as a framework for analyzing statistical models through differential geometry. The FIM naturally arises as the Hessian of the Kullback-Leibler divergence between nearby probability distributions, making it the canonical choice for measuring distances on the statistical manifold.

In the context of optimization, the FIM provides several key advantages:

1. **Coordinate covariance**: The exact undamped natural-gradient vector field transforms consistently under smooth invertible reparameterization. Finite Euler steps, ridge damping, and lattice rounding need not preserve that invariance.

2. **Directional scaling**: The solve rescales gradient components by the supplied metric. The caller still chooses a step size; poorly chosen metrics or steps can destabilize descent.

3. **Scope**: No convergence-rate or robustness advantage follows from tetrahedral coordinates alone.

### 4D Framework Integration through Fisher Information

**Coxeter.4D (Euclidean)**: In standard Euclidean parameter space, the metric tensor is simply $\delta_{ij}$, providing uniform scaling in all directions. The FIM $F_{ij}$ generalizes this to capture the actual curvature structure of the objective function.

**Einstein.4D (analogy only)**: Both subjects use metrics, but the Fisher metric is not a spacetime metric. Equation \eqref{eq:natural_gradient} defines metric steepest descent, not geodesic motion.

**Fuller.4D (coordinates)**: Pulling a three-parameter metric back through the Quadray embedding introduces a common-offset null direction. Use a quotient parameterization or explicit numerical damping; no four-independent-axis metric is implied.

### Natural gradient as metric steepest descent {#natural-gradient-descent-geodesic-motion-on-information-manifold}

`natural_gradient_step(gradient, fisher, step_size, ridge)` returns an increment, not the next parameter vector:

```python
import numpy as np
from quadmath.inference.information import natural_gradient_step

theta = np.array([1.0, -1.0])
gradient = theta.copy()
metric = np.diag([2.0, 1.0])
theta = theta + natural_gradient_step(gradient, metric, step_size=0.1)
```

The implementation solves $(F+\lambda I)\delta=\nabla L$ and returns $-\eta\delta$.
A fixed-metric preconditioned trajectory is not generally a geodesic, and no
universal speed or stability advantage is claimed.

![**Fixed-metric preconditioning on a quadratic bowl.** The loss Hessian is the declared positive-definite matrix $A$, while the preconditioner is the regression gradient Gram $F$. Twenty increments use $-0.5(F+10^{-3}I)^{-1}A(w-w_{\mathrm{true}})$, starting at $(2,2,2)$. The plot projects the three-parameter path onto its first two coordinates. Its final marker is a budget-limited iterate, not an exact optimum or a geodesic. Generated by `quadmath/scripts/information_demo.py`.](figures/natural_gradient_path.png)

### Quadray-Specific Considerations

A Quadray pullback has a gauge null direction; tetrahedral symmetry alone does not imply separable statistical parameters. Integer projection changes the proposal geometry and can introduce plateaus. Any hybrid requires an explicit projection schedule and task-specific evaluation.
